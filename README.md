
**大学陸上競技部における情報共有基盤の整備と組織運営改善**
Portfolio / Organizational Operations × Digital Transformation
Microsoft Teams · SharePoint · 情報設計 · 業務改善
**1. プロジェクト概要**
大学陸上競技部の短距離ブロック長として、複数キャンパスにまたがる組織の情報共有、文書管理、役員交代時の引継ぎを改善するための運営基盤整備に取り組んでいます。
このプロジェクトでは、ツールを導入すること自体ではなく、担当者が交代しても継続して使える運営の仕組みを設計することを重視しています。
担当領域： 課題整理、ツール比較・選定、情報共有構成の検討、文書管理・権限管理方針の設計、運営ルールの整備

公開上の注意： 本資料は就職活動用に再構成した概要です。部員の個人情報、内部文書、実際のアクセス権限や機密情報は公開していません。
**2. 背景と課題**
複数キャンパス間の連携： 活動場所や担当業務が分かれており、情報共有の方法を統一する必要がある。
資料の継承： 役員が毎年交代するため、次年度の担当者が過去の判断や資料を参照できる体制が必要。
情報の整理： 連絡、意思決定、文書保管の役割を明確にし、必要な情報にたどり着きやすくする必要がある。
権限管理： 現役役員への引継ぎと、卒業した役員のアクセス権限の整理を両立させる必要がある。
※上記は運営上の課題認識であり、定量的な改善効果を示すものではありません。

**3. 解決方針と技術選定**
Microsoft Teamsを日常的な連絡・議論の場、SharePointを文書管理・継承の基盤として位置づけています。
選定にあたっては、利用者の使いやすさに加えて、大学アカウントでの利用、次年度役員への所有者・管理権限の引継ぎ、卒業者のアクセス管理などを考慮しました。

観点	設計上の方針
日常連絡	Teamsのチャンネルで話題・担当領域を整理する
文書管理	SharePoint上で資料を分類・保管する
引継ぎ	次年度の現役役員が過去の資料を参照できる状態を目指す
権限管理	役割に応じてアクセス権限を見直す
運用継続性	特定の担当者だけに依存しないルールを整備する

**4. 設計・改善の取り組み**
**4.1 情報共有の設計****
幹部間の情報共有を目的としたTeamsの運用を検討・整備
チャンネル構成や投稿・周知方法を整理
情報を残す場所と、日常的に連絡する場所の役割分担を検討
**4.2 文書管理と引継ぎ**
SharePointを用いた資料の保管・継承方法を検討
年度をまたいだ役員交代を想定した管理方針を整理
過去の役員資料を現役の後任者が参照できる仕組みを重視
**4.3 組織運営ルール**
部則・会計規則の整備を検討
キャンパスや担当領域ごとの事情を踏まえた運用を意識
細部を固定しすぎず、次年度以降も見直せる方針を重視
**5. 取り組み状況と評価**
このプロジェクトは運用整備の途中段階です。現時点で定量的な効果測定は完了していません。
今後は、次のような観点で運用状況を確認したいと考えています。

必要な資料を探す時間や手間
連絡事項の周知漏れや重複
新任役員の引継ぎ負担
権限の付与・解除を適切に行えるか
実際に運用していくことによって生まれるであろうトラブルに対する対応
**6. この経験で発揮した能力**
課題発見力： 組織運営を担当する立場から、情報共有・引継ぎの課題を整理
システム設計の視点： 利用者、権限、保管場所、継続運用を一体で検討
技術選定力： 導入時の便利さだけでなく、長期的な管理体制を考慮
調整力： 複数キャンパス・担当領域の違いを踏まえて運営方針を検討
**7. 今後の展望**
運用を継続しながら、部員・役員の利用状況や引継ぎ時の課題を把握し、情報構成やルールを改善していきます。
